# Emplify -- Employee Management System

Emplify is a microservices-based Employee Management platform built using Spring Boot.
It manages employees and departments in a structured and scalable way and demonstrates real-world microservice communication.

This project is currently in progress as I am building it to learn and implement microservices architecture.

# Microservices Implemented

This project consists of:

- Employee Service
- Department Service

Each service runs independently and communicates with other services
using REST APIs.
